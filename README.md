# Artur Kich - Portfolio

Portfolio pessoal com design brutalista e editorial. 

## Tecnologias

* React
* Vite
* Tailwind CSS
* Framer Motion

## Instalação e Execução

1. Clone o repositório:
git clone https://github.com/felaaass/Portifolio-2026.git

2. Instale as dependências:
npm install

3. Execute o servidor:
npm run dev
